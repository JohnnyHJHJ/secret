# Design

## Visual World

**Dear OS workspace** — a warm, early-desktop study room: powder-blue desktop, ivory window surfaces, thin charcoal window rules, rose title ink, and compact pixel-adjacent details. This is an Operate surface: the nostalgic chrome frames the work rather than competing with it.

## Durable Decisions

- Use existing theme variables only; `Dear OS` is the default and the other themes remain selectable.
- Preserve the existing readable UI/display font stack.
- Keep all code editor and syntax-token colors unchanged from the original dark palette.
- Use square to subtly softened window controls, inset highlights, and restrained offset depth.
- The Collection is the default screen and the first rail destination.
- Responsive layouts collapse the rail into a horizontal toolbar and retain DOM/focus order.
