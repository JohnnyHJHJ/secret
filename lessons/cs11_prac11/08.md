Each spy corresponds to exactly one agent, and each agent to exactly one spy. To look up in **both directions** quickly we keep two dicts: `to_right` (agent to spy) and `to_left` (spy to agent).

::::quiz q-onedict
Why not keep just one dict `{agent: spy}` and search its values when you need the agent for a spy?

- [ ] Dicts cannot have strings as values
- [x] Searching the values of a dict looks at every item, which is slow for hundreds of thousands of pairs
- [ ] A dict can only hold one pair
:::hint
How does Python find a **key** in a dict? How does it find a **value**?
:::
:::hint
Keys are found at once. Values need a scan.
:::
:::explain
Dict keys are found in constant time, but searching values is a loop over everything. A second dict that maps back makes the other direction fast too. Note that an agent and a spy may have the same name, so the two directions must be two separate dicts, not one.
:::

```python solution
class OneToOneCorrespondence:
    def __init__(self, *pairs):
        self.to_right = {}
        self.to_left = {}
        for left, right in pairs:
            self.to_right[left] = right
            self.to_left[right] = left

    def get_right(self, v):
        if v not in self.to_right:
            raise ValueError('no such agent')
        return self.to_right[v]

    def get_left(self, v):
        if v not in self.to_left:
            raise ValueError('no such spy')
        return self.to_left[v]
```

:::hint
Use `raise ValueError('some message')` when the name is missing.
:::
:::explain
`d[v]` on a missing key would raise `KeyError`, but the problem demands `ValueError`. So test first, raise the right error, and only then return the value. Agents use `to_right`, spies use `to_left`.

Now the most important rule of this lesson. `set_pair(l, r)` must refuse if the agent `l` **or** the spy `r` already has a partner.

::::quiz q-order
In `set_pair`, which order keeps the data consistent when the call must be refused?

- [x] Check both conditions first, then write to both dicts
- [ ] Write the agent to its dict, then check the spy and raise if it is taken
- [ ] Write to both dicts, then check and raise if either was already there
:::hint
Imagine the error is raised halfway through the method. What state are the dicts left in?
:::
:::hint
A refused call must change **nothing**.
:::
:::explain
If you raise after changing one dict, a refused call still leaves a half pair behind and the dicts disagree forever. Validate everything first and change things last.
:::

::::exercise ex-partial kind=debug
`set_pair` is supposed to refuse a pair if the agent or the spy is already used, and to change nothing when it refuses. Sometimes a refused call leaves a half pair behind. Fix it.

```python starter
class OneToOneCorrespondence:
    def __init__(self, *pairs):
        self.to_right = {}
        self.to_left = {}
        for left, right in pairs:
            self.set_pair(left, right)

    def get_right(self, v):
        if v not in self.to_right:
            raise ValueError('no such agent')
        return self.to_right[v]

    def get_left(self, v):
        if v not in self.to_left:
            raise ValueError('no such spy')
        return self.to_left[v]

    def set_pair(self, l, r):
        if l in self.to_right:
            raise ValueError('agent already paired')
        self.to_right[l] = r
        if r in self.to_left:
            raise ValueError('spy already paired')
        self.to_left[r] = l
```

```python solution
class OneToOneCorrespondence:

        self.to_right = {}
        self.to_left = {}
        for left, right in pairs:
            self.set_pair(left, right)

            raise ValueError('no such agent')
        return self.to_right[v]

        if v not in self.to_left:
            raise ValueError('no such spy')
        return self.to_left[v]

    def set_pair(self, l, r):

        self.to_right[l] = r
        self.to_left[r] = l
```

:::hint
Which line changes a dict before the second condition has been checked?
:::
:::hint
Put both checks at the top, joined with `or`, then do both writes.
:::
:::explain
A refused call used to write the agent and then raise on the spy. Now both conditions are checked first, so a refusal changes nothing. The constructor also benefits, because it simply calls `set_pair` for each pair.

```python solution
class OneToOneCorrespondence:
    def __init__(self, *pairs):
        self.to_right = {}
        self.to_left = {}
        for left, right in pairs:
            self.set_pair(left, right)

    def get_right(self, v):
        if v not in self.to_right:
            raise ValueError('no such agent')
        return self.to_right[v]

    def get_left(self, v):
        if v not in self.to_left:
            raise ValueError('no such spy')
        return self.to_left[v]

    def set_pair(self, l, r):
        if l in self.to_right or r in self.to_left:
            raise ValueError('already paired')
        self.to_right[l] = r
        self.to_left[r] = l

    def remove_pair_with_left(self, v):
        if v not in self.to_right:
            raise ValueError('no such agent')
        right = self.to_right.pop(v)
        del self.to_left[right]

    def remove_pair_with_right(self, v):
        if v not in self.to_left:
            raise ValueError('no such spy')
        left = self.to_left.pop(v)
        del self.to_right[left]
```

:::hint
`partner = self.to_right.pop(v)` removes from one dict and tells you the partner.
:::
:::hint
Then delete the partner from the other dict: `del self.to_left[partner]`.
:::
:::explain
Forgetting the second dict would leave the spy marked as taken forever. Each dict is cleaned with the key that belongs to it: the agent in `to_right`, the spy in `to_left`.

The code before `yield` runs when the `with` block starts, and the code after `yield` runs when it ends. An error inside the block shows up at the `yield`.

::::exercise ex-raises kind=write
Write the context manager `raises_value_error()`. A `with raises_value_error():` block passes if the block raises `ValueError`. If the block raises nothing, the context manager must fail with an `AssertionError`. (Use `try`, `yield`, `except ValueError`, and `else`.)

```python tests
def good():
    with raises_value_error():
        raise ValueError('boom')
    return 'passed'

def nothing_raised():
    try:
        with raises_value_error():
            pass
    except AssertionError:
        return 'failed as it should'
    return 'wrongly passed'

def other_error():
    try:
        with raises_value_error():
            raise KeyError('x')
    except KeyError:
        return 'other errors pass through'
    return 'swallowed'

check(good, 'passed', "a ValueError is accepted")
check(nothing_raised, 'failed as it should', "no error means the check fails")
check(other_error, 'other errors pass through', "a different error is not swallowed")
check(uses('Try'), True, "uses try")
```
```python solution
from contextlib import contextmanager

@contextmanager
def raises_value_error():
    try:
        yield
    except ValueError:
        pass
    else:
        assert False
```
:::hint
Wrap the `yield` in a `try`.
:::
:::hint
`except ValueError: pass` accepts the error. The `else` branch of a `try` runs only when nothing was raised.
:::
:::explain
`else` runs when the `try` block finished without an exception, which is exactly the case we must reject. `assert False` always raises `AssertionError`. Errors other than `ValueError` are not caught, so they pass through unchanged.
:::

```python solution
        self.to_right = {}
        self.to_left = {}
        for left, right in pairs:
            self.set_pair(left, right)

    def get_right(self, v):
        if v not in self.to_right:
            raise ValueError('no such agent')
        return self.to_right[v]

    def get_left(self, v):
        if v not in self.to_left:
            raise ValueError('no such spy')
        return self.to_left[v]

    def set_pair(self, l, r):
        if l in self.to_right or r in self.to_left:
            raise ValueError('already paired')
        self.to_right[l] = r
        self.to_left[r] = l

    def remove_pair_with_left(self, v):
        if v not in self.to_right:
            raise ValueError('no such agent')
        right = self.to_right.pop(v)
        del self.to_left[right]

    def remove_pair_with_right(self, v):

            raise ValueError('no such spy')
        left = self.to_left.pop(v)
```

:::hint
Two dicts: one from agent to spy, one from spy to agent.
:::
:::hint
Let the constructor call `set_pair` for each pair, so the duplicate checks are written only once.
:::
:::hint
In every method: check first, change last. In the remove methods use `pop` to learn the partner, then delete the partner from the other dict.
:::
:::explain
Every operation is a few dict lookups, so each call costs a tiny constant time, however many pairs exist. The rules you applied: two dicts for two directions, raise `ValueError` before changing anything, and always update both dicts together.
