# Painted Rectangles and Layers

:::goal What you will be able to do
- Keep one bounding box per colour in a dict.
- Turn a bounding box into (rows, columns) without an off-by-one mistake.
- Decide which of two overlapping rectangles was painted last.
- Solve the Criss Cross problem.
:::

In Criss Cross, a painter paints one rectangle and then a second one that crosses it. Colours are letters and a space is white. You see the finished painting and must say how big each rectangle is.

The back rectangle is partly hidden. But the **bounding box** of a colour (the smallest box that contains every cell of that colour) still equals the real rectangle, because both rectangles stick out on both ends of the crossing.

For every colour we need four numbers: the top row, the left column, the bottom row and the right column. Each new cell of that colour may push one of them outward.

::::fill f-box
```python
def extents(grid):
    box = {}
    for r, row in enumerate(grid):
        for c, ch in enumerate(row):
            if ch == ' ':
                continue
            if ch not in box:
                box[ch] = (r, c, r, c)
            else:
                top, left, bottom, right = box[ch]
                box[ch] = ([[min]](top, r), min(left, c), [[max]](bottom, r), max(right, c))
    return box
```
:::hint
The top is the smallest row seen, the bottom is the largest.
:::
:::hint
Which built-in function gives the smaller of two numbers? And the larger?
:::
:::explain
The first cell of a colour creates a box with only that cell. Every later cell can only enlarge it: `min` for top and left, `max` for bottom and right.
:::

:::hint
Loop over every cell with `enumerate`. Skip the spaces.

Now measure. A rectangle that covers rows 3 and 4 is **two** rows tall, not one. Count both ends.

::::quiz q-plus1
A rectangle covers rows 3 to 4 and columns 2 to 14. What are its dimensions as `(rows, columns)`?

- [ ] `(1, 12)`
- [x] `(2, 13)`
- [ ] `(13, 2)`
:::hint
Rows 3 and 4: how many rows is that?
:::

:::
:::explain
The count of numbers from `a` to `b` including both ends is `b - a + 1`. That gives 2 rows and 13 columns. Forgetting the `+ 1` and swapping rows and columns are the two classic mistakes.

Which rectangle is in front? The one painted last is completely visible. The one painted first has some of its cells covered. So:

- count the cells of a colour, **visible**;
- compute the area of its bounding box, **height times width**;
- the colour whose visible count equals the area is in front.

::::quiz q-front
In a criss-cross painting, how can you tell that a colour is the **front** rectangle?

- [ ] It is the colour with more cells
- [ ] It is the letter that comes first in the alphabet
- [x] Its number of visible cells equals the area of its bounding box
:::hint
The back rectangle loses some cells where the front one covers it.
:::
:::hint
A rectangle with nothing hidden has exactly as many cells as its bounding box.
:::
:::explain
The front rectangle is never covered, so all `height * width` cells are visible. The back one is covered at the crossing, so it shows fewer cells than its area. Size and letter name say nothing about the order.
:::

::::exercise ex-info kind=complete
Finish `rect_info(grid)`: return a dict that maps every colour to `(height, width, visible)`, where `visible` is the number of cells of that colour. `extents` and `dimensions` are given.

```python starter
def extents(grid):
    box = {}
    for r, row in enumerate(grid):
        for c, ch in enumerate(row):
            if ch == ' ':

            if ch not in box:
                box[ch] = (r, c, r, c)
            else:

                box[ch] = (min(top, r), min(left, c), max(bottom, r), max(right, c))
    return box

def dimensions(box):
    top, left, bottom, right = box
    return (bottom - top + 1, right - left + 1)

def rect_info(grid):
    boxes = extents(grid)
    info = {}
    return info
```

```python solution
def extents(grid):
    box = {}
    for r, row in enumerate(grid):
        for c, ch in enumerate(row):
            if ch == ' ':
                continue
            if ch not in box:
                box[ch] = (r, c, r, c)
            else:
                top, left, bottom, right = box[ch]
                box[ch] = (min(top, r), min(left, c), max(bottom, r), max(right, c))
    return box

def dimensions(box):
    top, left, bottom, right = box
    return (bottom - top + 1, right - left + 1)

def rect_info(grid):
    boxes = extents(grid)
    info = {}
    for ch, box in boxes.items():
        height, width = dimensions(box)
        visible = sum(row.count(ch) for row in grid)
        info[ch] = (height, width, visible)
    return info
```
:::hint
Loop over `boxes.items()` to get each colour and its box.
:::
:::hint
The number of visible cells is the total of `row.count(ch)` over all rows.
:::
:::explain
Counting a letter in each row and adding the counts gives the visible cells. Keeping the three numbers together makes the final decision a simple comparison.
:::

::::exercise ex-criss kind=challenge
Write `criss_cross_dimensions(grid)`: return `((rows, cols) of the front rectangle, (rows, cols) of the back rectangle)`. The grid holds exactly two colours that cross each other. `rect_info` is given.

```python solution
def extents(grid):
    box = {}
    for r, row in enumerate(grid):
        for c, ch in enumerate(row):
            if ch == ' ':
                continue
            if ch not in box:
                box[ch] = (r, c, r, c)
            else:
                top, left, bottom, right = box[ch]
                box[ch] = (min(top, r), min(left, c), max(bottom, r), max(right, c))
    return box

def dimensions(box):
    top, left, bottom, right = box
    return (bottom - top + 1, right - left + 1)

def rect_info(grid):
    boxes = extents(grid)
    info = {}
    for ch, box in boxes.items():
        height, width = dimensions(box)
        visible = sum(row.count(ch) for row in grid)
        info[ch] = (height, width, visible)
    return info

def criss_cross_dimensions(grid):
    info = rect_info(grid)
    ordered = sorted(info.values(), key=lambda t: t[2] != t[0] * t[1])
    front, back = ordered
    return ((front[0], front[1]), (back[0], back[1]))
```
:::hint
Use `rect_info`. For each colour, compare `visible` with `height * width`.
:::
:::hint
Sort the two entries so that the one with `visible == height * width` comes first. A sort key of `visible != height * width` puts `False` (the front) first.
:::
:::hint
Return the `(height, width)` of the first, then of the second.
:::
:::explain
A boolean works as a sort key: `False` sorts before `True`. The front rectangle has nothing hidden, so its test `visible != area` is `False`. Dimensions come in `(rows, columns)` order, exactly as the problem asks.
:::
::::

:::recap
- A dict of bounding boxes keeps four numbers per colour, grown with `min` and `max`.
- Size of a range including both ends: `bottom - top + 1`.
- Return pairs in the order the problem states, here `(rows, columns)`.
- The front layer is the one with nothing hidden: visible cells equal bounding-box area.
:::
