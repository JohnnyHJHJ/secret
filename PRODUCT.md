# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

CS 11 students using a local study and practice application to learn lessons, solve programming problems, and track progress.

## Product Purpose

Local Judge combines reading lessons, a code judge, collection organization, streak tracking, and optional class sync in one local web app.

## Operating Context

The app runs locally in an app-style browser window. Students use it at a desktop or laptop and may return repeatedly to choose the next lesson or coding problem.

## Capabilities and Constraints

Existing lessons, problems, organization data, sync, keyboard shortcuts, editor behavior, and syntax colors are preserved. The Collection screen is the initial selector. Colors remain configurable through `web/themes.css` and Settings.

## Brand Commitments

The redesign is a warm, nostalgic desktop-window theme inspired by the supplied reference. Keep the current readable system font stack and terminal syntax palette.

## Evidence on Hand

The repository includes runnable local-web UI code under `web/`, user lesson/problem data, and the supplied visual reference image. No external product claims or assets are introduced.

## Product Principles

- Put choosing the next piece of work first.
- Make organization feel direct and reversible.
- Preserve readability over decorative novelty.
- Keep the coding environment familiar and high contrast.
